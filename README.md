# Ruqqab

**Take Control of Every Expense.**

Ruqqab مشروع منصة SaaS لإدارة المصروفات والعمليات المالية داخل الشركات. الهدف هو تنظيم دورة المصروف من تقديم الطلب، مروراً بالموافقة والمراجعة، حتى تسجيل الدفع، بدلاً من توزيعها بين Excel وWhatsApp والمستندات الورقية.

> **حالة المشروع: مرحلة التخطيط.** هذا المستند يصف الرؤية والخصائص المقترحة، وليس خصائص منفذة أو خدمة متاحة للاستخدام. نطاق النسخة الأولى والتقنيات لم يُحددا بعد.

## المشكلة

عندما تتوزع طلبات المصروفات والموافقات والفواتير بين أكثر من مكان، تصبح متابعة الإنفاق ومراجعة مستنداته أصعب. تسعى Ruqqab إلى جمع هذه الدورة في مكان واحد، بحيث يمكن معرفة:

- ما المصروف، وما سببه، ولأي قسم؟
- من قدّم الطلب، ومن وافق عليه؟
- أين الفاتورة أو المستند الداعم؟
- هل الطلب قيد الموافقة، أم تمت الموافقة عليه، أم سُجّل دفعه، أم رُفض؟

## دورة العمل المقترحة

1. **تقديم الطلب:** يُدخل الموظف اسم المصروف والمبلغ والقسم والسبب، ويرفق الفاتورة أو المستند عند توفره.
2. **الموافقة:** يراجع المدير الطلب ويوافق عليه أو يرفضه أو يطلب تعديلات، مع تسجيل القرار.
3. **المراجعة المالية:** تتابع الإدارة المالية الطلب المعتمد ومستنداته، ثم تسجّل حالة الدفع.
4. **المتابعة:** يطّلع صاحب الشركة على ملخص المصروفات وحالات الطلبات وإنفاق الأقسام من لوحة تحكم واحدة.

المقصود هنا هو **تسجيل الدفع ومتابعته**، وليس تنفيذ تحويلات مالية عبر المنصة.

## المستخدمون المستهدفون

- **صاحب الشركة / مسؤول النظام:** الاطلاع على بيانات الشركة وإدارة إعداداتها وصلاحياتها.
- **المدير المالي:** متابعة المصروفات والميزانيات والفواتير.
- **المحاسب:** مراجعة المصروفات والمستندات والمدفوعات المسجلة.
- **مدير القسم:** مراجعة طلبات موظفي قسمه.
- **الموظف:** تقديم طلبات المصروفات ومتابعة حالتها.

هذه أدوار مبدئية، وتفاصيل الصلاحيات جزء من تصميم المنتج لاحقاً.

## الوحدات المقترحة

| الوحدة | الغرض |
| --- | --- |
| Dashboard | ملخص الإنفاق وحالات الطلبات |
| Expenses | طلبات المصروفات ومتابعتها |
| Approvals | قرارات الموافقة والرفض وطلبات التعديل |
| Invoices | الفواتير والمستندات المرتبطة بالمصروفات |
| Budgets | ميزانيات الأقسام ومتابعة الإنفاق مقابلها |
| Departments | إدارة الأقسام |
| Employees | إدارة الموظفين وأدوارهم |
| Vendors | إدارة الموردين |
| Reports | تقارير المصروفات والعمليات المالية |
| Audit Logs | سجل القرارات والعمليات |
| Settings | إعدادات الشركة |

هذه قائمة للرؤية العامة، وليست التزاماً بتضمين كل الوحدات في النسخة الأولى.

## اتجاه المنتج

يشمل التصور دعم العربية والإنجليزية، والعملات المتعددة، والصلاحيات حسب الأدوار، والموافقات متعددة المستويات، والإشعارات، وتقارير واضحة للاستخدام من الكمبيوتر والموبايل.

تحليل المصروفات بالذكاء الاصطناعي واكتشاف الأنماط غير الطبيعية أفكار مستقبلية، وليست ضمن نطاق منفذ أو معتمد حالياً.

## النسخة الأولى (MVP)

الخطوة التالية هي تحديد أصغر دورة عمل يمكن اختبارها مع شركات فعلية، والتحقق من احتياجها قبل التوسع في الخصائص. يوجد اقتراح أولي للنطاق في [docs/MVP.md](docs/MVP.md) بانتظار الاعتماد.

## نموذج الاشتراك

التصور المبدئي هو اشتراكات شهرية وسنوية. أسماء الباقات والأسعار والفترة التجريبية والإضافات المدفوعة ما زالت أفكاراً للتخطيط، وليست باقات أو عروضاً معلنة.

## التشغيل والتطوير

لم تُحدد التقنيات أو متطلبات التشغيل بعد. ستُضاف خطوات التثبيت والإعداد والاختبار عند وجود تنفيذ يمكن التحقق منه، بدلاً من نشر أوامر تشغيل غير قابلة للاستخدام.
